# Documentation Site Guide

Consider:

- route and router compatibility;
- static, server, or hybrid rendering;
- direct navigation and refresh behavior, including static-hosting rewrite rules;
- hosting rewrites, asset/base paths, and subpath deployment;
- navigation hierarchy;
- search;
- mobile navigation;
- syntax highlighting and copy behavior;
- executable or validated examples;
- versioning;
- SEO metadata;
- accessibility;
- theme and authentication boundaries;
- analytics or feedback;
- support for the user's actual clients and tools;
- content ownership and update workflow.

Prefer a working HTML or component prototype when visual and interaction requirements are hard to express in prose.
