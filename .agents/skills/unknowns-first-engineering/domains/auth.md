# Authentication and Authorization

- Identify identities, credentials, sessions, tokens, roles, and trust boundaries.
- Distinguish authentication from authorization.
- Preserve secure defaults, expiry, revocation, replay resistance, and least privilege.
- Validate redirect URIs, origins, audiences, issuers, and token signatures as relevant.
- Never log secrets, raw passwords, private tokens, or sensitive proof material.
- Test valid, invalid, expired, revoked, unauthorized, and cross-tenant cases.
- Require approval before changing externally visible auth behavior or weakening controls.
