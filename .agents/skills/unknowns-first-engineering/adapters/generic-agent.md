# Generic Agent Adapter

When the host has no native skill system, include the core behavior in its system/project instructions and load references manually.

Minimum loop:

1. Define goal and success criteria.
2. Inspect relevant context.
3. State material assumptions.
4. Make the smallest correct change.
5. Use available tools to verify.
6. Repeat only while evidence shows progress.
7. Report checked and unchecked criteria honestly.

Do not invent unavailable capabilities such as subagents, terminal access, browser execution, persistent memory, or automatic file discovery.
